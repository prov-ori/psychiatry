# Психиатрия: от нуля до эксперта

Интерактивная платформа для изучения психиатрии на русском языке — от «что такое психиатрия» до резистентной шизофрении, судебной экспертизы и чтения клинических исследований. Ориентирована на студентов-медиков в **Эстонии**: эстонское право (PsAS, KarS, опека), система здравоохранения, наличие препаратов, эстонские эквиваленты терминов и подготовка к экзамену.

Без сборки, без сервера и без зависимостей: чистый HTML, CSS и JavaScript. Прогресс хранится в браузере (`localStorage`).

### Уровни

0. **Фундамент** — что такое психиатрия, норма и патология, история, биопсихосоциальная модель, классификации, права пациента.
1. **Нейронаука** — анатомия, синапс, дофаминовые пути, моноамины, глутамат и ГАМК, генетика, стресс и воспаление.
2. **Психопатология** — интервью, психический статус, расстройства восприятия, мышления, эмоций, воли, сознания и памяти, синдромы.
3. **Клиническая психиатрия** — психозы, депрессия, БАР, тревога, ОКР, травма, расстройства личности, РПП, зависимости, деменции, детская психиатрия, соматоформные расстройства и сон.
4. **Лечение** — принципы фармакологии, антидепрессанты, антипсихотики, нормотимики, анксиолитики, КПТ и другие психотерапии, ЭСТ/ТМС/кетамин.
5. **Экспертный** — суицидальный риск, неотложные состояния, резистентность, консультативная и судебная психиатрия (по эстонскому праву), беременность и пожилые, доказательная медицина, фронтир науки, клиническое мышление.

**Модуль «Эстония»** — устройство психиатрической помощи (Tervisekassa, perearst, прямой доступ к психиатру, erihoolekanne), Закон о психиатрической помощи на практике, психический статус по-эстонски, эпидемиология и особенности страны, подготовка к экзамену и глава V RHK-10 на эстонском.

Правовые нормы приведены по состоянию на 2026 год. Перед экзаменом сверяйте актуальную редакцию законов на riigiteataja.ee и формулировки с лекциями кафедры.

## Запуск

Откройте `index.html` в браузере — всё. Сервер не нужен.

Для публикации через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root. Файл `.nojekyll` уже есть.

Один самодостаточный файл (удобно отправить или открыть офлайн):

```bash
node tools/build-single.js      # → dist/psychiatry.html
```

## Логотип и превью для соцсетей

Знак — симметричное чернильное пятно в духе теста Роршаха, цвет — метиленовый синий (краситель, с которого началась химия фенотиазинов и хлорпромазина). Файлы лежат в `assets/img/`: `og-image.png` (превью 1200×630), `logo.png`, иконки и фавиконки.

Мета-теги Open Graph и Twitter в `index.html` указывают на `https://prov-ori.github.io/psychiatry/`. Если сайт будет жить по другому адресу, замените этот адрес во всех тегах `og:*`, `twitter:*` и `canonical` — соцсети принимают только абсолютные ссылки.

Перегенерировать изображения (нужен Playwright):

```bash
node tools/make-brand.js
```

## Как добавлять контент

Урок — объект в `data/curriculum-N.js`:

```js
{ id: 'l3-15', title: '…', minutes: 10, summary: '…',
  content: `<h3>…</h3><p>… <span class="t">бред</span> …</p>`,
  keyPoints: ['…'],
  quiz: [{ q: '…', options: ['…', '…'], answer: 1, explain: '…' }] }
```

- `answer` — индекс правильного варианта или массив индексов для вопроса с несколькими ответами.
- `<span class="t">термин</span>` делает слово кликабельным; форма слова, отличная от глоссария, задаётся так: `<span class="t" data-t="бред">бредовых</span>`.
- Блоки-выноски: `<div class="callout pearl|warn|mnemo|myth|quote">…</div>`.

После правок запустите проверку — она ловит неверные индексы ответов, дубли id, ссылки на несуществующие уроки и термины без статьи в глоссарии:

```bash
node tools/validate.js
```
